## 背景
现有 chanlun_backtest/ 框架使用均线版(MA20/MA40/MA160 + 资金面因子)。
用户要求改为结构版(MACD(20,40,5) + 纯结构缠论笔/中枢/买卖点)。

## 与现有框架的差异

| 维度 | 现有均线版 | 结构版(定版) |
|------|-----------|-------------|
| 指标 | MA20/40/160 + MACD(12,26,9) | MACD(20,40,5) 定版 |
| 结构 | 均线交叉定趋势 | 包含→分型→笔→中枢 |
| 买卖点 | 回调+资金面因子过滤 | 背驰面积+几何条件 |
| 信号 | 二买/三买/二卖/三卖 | B1/S1/B2/S2/B3/S3 |

## 结构版核心算法

### 模块A: K线包含
```
包含: k.high>=last.high and k.low<=last.low (或反向)
上升合并取高, 下降合并取低
```

### 模块B: 分型
```
顶: middle.high > prev.high and middle.high > next.high
底: middle.low < prev.low and middle.low < next.low
```

### 模块C: 笔
```
异向交替, 最小间隔5根合并K线, 同向取极端
```

### 模块E: 中枢
```
连续3段(4端点)重叠: ZD=max(段低), ZG=min(段高), ZG>ZD
```

### 模块F: 买卖点
```
B1: 底背驰(段2创新低 + 柱面积2 < 柱面积1×0.9)
S1: 顶背驰(对称)
B2: 一买后回调不破前低(3~50根K线内)
S2: 一卖后反弹不破前高
B3: 中枢上沿上方回抽不破ZG
S3: 中枢下沿下方回抽不破ZD
```

### 回测参数
- 次根收盘成交, 只做多
- 双边成本0.2%, 复利连乘
- MACD(20,40,5) 三级别统一
