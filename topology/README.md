# topology · SPD 流形 + TDA + 里奇曲率 拓扑流形分析

> 对 **指数 / 行业 / 概念 / 板块** 做「成分股协方差 SPD 流形」分析，
> 用 **H1 环寿命 × 平均相关性** 二维化出「机会 / 风险」相位图。
> 全流程纯 Python 数值计算（numpy / scipy / ripser / matplotlib），零 LLM，绝不编数据。

## 一句话原理

把成分股的日度收益映射成高维点云，看两件事：

- **同步度（横轴）**：成分股平均两两相关 corr —— 越高越「一起涨跌 = 锁死」。
- **拓扑再生度（纵轴）**：Vietoris-Rips H1 环寿命 —— 点云中间有洞 = 市场存在
  独立方向阵营 = 分化机会；环塌缩 = 全市场同步 = 系统性风险。

两个维度正交，切出四个象限：

|            | H1 环重生（上） | H1 环塌缩（下） |
|------------|:---:|:---:|
| **低相关（左）** | 🟦 机会区（分化·结构解冻） | 🟨 磨底区（假反弹） |
| **高相关（右）** | 🟧 警惕区（伪分化） | 🟥 风险区（同步·锁死） |

## 目录

```
topology/
├── run.py           # 统一入口（CLI）
├── targets.py       # 标的解析与类型识别（指数/行业/概念/板块）
├── data_loader.py   # 取数层（走 dh_bridge，失败降级 data_hub）
├── spd.py           # SPD 流形 + TDA + 里奇曲率 指标计算
├── plot.py          # 画图（单标的四合一图 / 多标的二维相位图）
└── README.md
```

## 用法

```bash
# 单指数
python3 topology/run.py --target 沪深300

# 多指数（逗号分隔）
python3 topology/run.py --target 沪深300,科创50,中证500,上证50,创业板指

# 混类型（多次 --target）
python3 topology/run.py --target 指数:沪深300 --target 行业:电子

# 概念 / 板块
python3 topology/run.py --target 概念:人工智能 --target 板块:半导体

# 列出支持的标的
python3 topology/run.py --list
```

### 参数说明

| 参数 | 说明 |
|---|---|
| `--target` | 目标标的，可多次 / 逗号分隔 / 混类型。类型前缀：`指数:` `行业:` `概念:` `板块:` `个股:` |
| `--days` | 收益窗口交易日数（默认 60，实际取 `days+1` 个交易日收盘） |
| `--out` | 输出目录（默认 `reports/topology`） |
| `--no-spd` | 不画单标的四合一 SPD 流形图 |
| `--no-phase` | 不画多标的二维相位图 |
| `--list` | 列出支持的指数 / 行业 / 概念 |

无前缀时的自动识别顺序：**指数代码/名称 → 行业名 → 概念名 → 板块名**。

## 输出

- `<名字>_SPD流形图.png` —— 每个目标一张四合一图：
  左上 SPD 测地距离曲面（平滑流形）、右上 TDA 尖刺地形 + H1 发光环、
  左下 指数/标的收盘金线 + 红蓝黄分区、右下 里奇 + 测地 ｜ H1 + 相关性。
- `SPD流形二维相位图.png` —— 所有目标叠一张的「机会 / 风险」相位图（含 H1 环机理说明）。

## 已知限制

- **概念板块取不到成分股**（`dh_bridge.sector_members` 概念为 ajax 取不到），
  暂无法做成分股 SPD 流形，会被跳过并提示；行业板块、指数正常支持。
- **个股**无成分股，SPD 流形分析不支持（会明确提示跳过）。
- 依赖 `ripser`（H1 环）与 `scipy`，见仓库根 `requirements.txt`。
