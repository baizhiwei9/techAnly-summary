# SMC 买点口径对比：远程 `chan_smc_index.smc_read` vs 本地 `smc/smc_core.py`

日期：2026-11-11 ｜ 数据：沪深300ETF（sh510300）、创业板ETF（sz159915）日线，最近 400 根，摆动点 k=3

## 一、结论先行

**两者不是同一个「买点」定义，不能按同一口径互相校验。**

- 远程 `smc_read` 是**结构播报器**：只有「价格是否高于最近摆动高」和位置/机会/风险文字，**没有买点确认，也没有入场触发**。
- 本地 `smc_core.confirm_zone` 是**完整买点规则**：FVG/OB 区域 → 不破 + 已回踩 + 方向确认 + 不走远，四段判定后才输出 `buy`。
- 因此历史重叠率很低：远程「转多」的交易日里，本地只认 **11%～19%**。

## 二、能力对照

| 维度 | 远程 `smc_read` | 本地 `smc_core` |
|---|---|---|
| 摆动点 | `pivots(df,k)` | 同款 `pivots(df,k)`（代码一致） |
| 结构 | 最近 2 高 + 2 低 → HH/HL/LH/LL/扩张/收敛 | 同款摆动点，但用于 FVG/OB/CHoCH |
| FVG（公允价值缺口） | ❌ | ✅ 3 根失衡，记录回补进度/强度 |
| OB（订单块） | ❌ | ✅ CHoCH/BOS 前的反向 K 线 |
| 买点确认 | ❌ 仅 `P > H1` | ✅ A 不破 + B 已回踩 + C 方向≥2/4 + D ≤1×ATR |
| 新鲜度 | ❌ 状态持续，不区分「今天突破」 | ✅ 每个 zone 有 age / state（buy / wait_up / wait_retest / extended / broken） |
| 入场/止损 | ❌ | ✅ 回测在 SUB 做多 CHoCH 入场；期货 2×ATR 跟踪止损 |
| 输出用途 | 四层汇总里的「机会/风险」文字 | 可独立出信号、可回测 |

## 三、实测差异（最近 400 根日线）

| 标的 | 远程 `P>最近摆动高` 天数 | 最长连续天数 | 本地 `state=buy` 天数 | 同时成立 | 占远程 | 占本地 |
|---|---:|---:|---:|---:|---:|---:|
| sh510300 | 69 / 400（17.2%） | **15 天** | 66 | 13 | 18.8% | 19.7% |
| sz159915 | 107 / 400（26.8%） | **27 天** | 48 | 12 | 11.2% | 25.0% |

最长连续 27 天说明：远程的「已上破摆动高 → 转多信号」不是突破当天的事件，而是**价格待在上方就一直成立的状态**。

## 四、远程侧的问题（按严重度）

1. **BOS/转多不是事件，会长期重复**
   `bin/chan_smc_index.py:298` 只判断 `P > H1`，没有「上穿发生在今天」、没有失效、没有去重。
   价格只要不跌回旧摆动高下方，就连续多日输出「已上破…转多信号」。实测最长 15/27 个交易日。

2. **摆动点有确认滞后，参考价天然是旧的**
   `pivots`（`:273`）要求左右各 k 根都确认，且计算时直接排除最后 k 根。
   k=3 时：**最近 3 根里的新高根本不会成为 H1**；突破发生当天用的还是 3+ 根以前的高点。
   等这个新高被确认成 H1，价格往往已经离开突破位，「机会」也就过期了。

3. **区间把不同腿的高点和低点拼在一起**
   `:305` `rng_h = max(H1,H2)`、`rng_l = min(L1,L2)`，高点和低点可能来自不同摆动腿。
   实测 sz159915：区间被算成 **2.51～3.49（宽 39%）**，现价 2.59，位置 8% → 输出「区间偏下，回踩可低吸」，
   但同一份结果的结构是「空头结构 (LH+LL)」。这是两套互相矛盾的提示。

4. **结构只用最近两个高/两个低**
   `:288-296` 一对摆动点就能把「多头/空头」翻面，噪音大；没有 HH/HL 序列、没有结构级别、没有破坏确认。

5. **`to_bos_up/dn` 在已破区间后为负**
   `:337-338` 公式仍叫「到上沿还有多少%」，价格已在上沿之上时为负数；
   渲染层（`:765`）靠再取负号显示，字段语义不稳，其他调用方容易误用。

6. **没有任何可执行买点要素**
   无 FVG/OB、无回踩、无方向确认、无 ATR 距离、无止损、无仓位。
   如果直接拿它当买点，等于「价格在旧摆动高上方就买」，会在区间上沿追高，也无法区分突破回踩和假突破。

## 五、本地侧需要说明的点（不是「远程 bug」，但影响结果）

1. **`pivots` 与远程完全相同**，所以摆动点算法本身不是差异来源；差异全部来自买点规则。
2. **方向确认的「破前高」用收盘价对比前 `win` 根最高价**
   `confirm_zone` 中 `newhigh = px > max(high[i-win:i])`，是偏严的口径（收盘破最高价），
   跳空强势时可能晚 1 根确认；这是保守选择，不是错误。
3. **OB 的「已回踩」门槛偏松**
   `find_order_blocks` 的 `touched = min(low[idx+1:]) <= top`；OB 的 top 是那根 K 线的高点，
   后续 K 线只要低点落到该高点下方就算「回踩」。多数情况下下一根就满足。
   真正区分强弱的是 C（方向 2/4）和 D（≤1 ATR），B 本身约束不强。
4. **`pick_signals` 只取前 3 个 FVG + 前 3 个 OB**
   `smc_core.py:488` 的候选截断是展示层选择（按新鲜度/强度/年龄排序），
   不会改变已选中 zone 的判定，但可能漏掉排在第 4 位的有效 zone。

## 六、统一结论（2026-11-11 定稿）

- **SMC 只有一个口径：本地 `smc/smc_core.py`**。
  - `smc_core.smc_layer(df, k)` 是唯一组装入口（摆动点 + FVG/OB + `confirm_zone`）。
  - `bin/chan_smc_index.py::smc_local()` 与 `bin/tech_summary.py::smc_layer()` 都调它。
  - 原远程 `smc_read`（价格 > 旧摆动高）已从 `chan_smc_index.py` 移除；仅在 `chanlun_multiscale/chanlun_backtest/vendor/` 保留逐字节副本，供历史对比脚本使用。
- 日报里的 SMC 行改为：结构上下文 + FVG/OB 新鲜数 + `confirm_zone` 确认信号；不再输出「长期转多状态」。
- 后续可把 OB 的 B 条件从「碰 top」收紧到「进入 zone 上半区/回踩不破下沿」，再用回测验证；届时只改 `smc_core` 一处。

## 七、复现

- 本地（现行）：`smc_core.smc_layer(df, k)`；逐根验证时用 `find_fvgs` → `find_order_blocks` → `pick_signals(df, end=i)`。
- 远程（仅归档对比）：`chanlun_multiscale/chanlun_backtest/vendor/chan_smc_index.py::smc_read`，逐根喂 `df.iloc[:i+1]`。
