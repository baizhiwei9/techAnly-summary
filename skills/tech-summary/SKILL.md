# 技术分析汇总（四层 + 买点分析）

> 一个标的，四套口径，日线 + 小时线，报告 + 两张图 + 飞书卡片。
> 实现：`bin/tech_summary.py`（单标的四层）+ `bin/tech_buypoint.py`（买点分析，指数/行业/概念/个股）
>
> **全流程纯 Python，不依赖任何大模型 / LLM API，0 token。**
> 脚本开头保留禁 IPv6 的 `socket.getaddrinfo` 过滤（容器 IPv6 不通会静默卡死）。

## 一、这个技能干什么

大佬 2026-11-09：「用那几个技术分析的技能分析一下中证500的指数，然后给出一个分析图来。
日线的，还有小时级别的，就是那两个缠论的。都分析了，还有那个 SMC，最后再画上 VWAP 的那几个分位数。」
「我可能将来不单单是中证500，可能分析指数，可能分析股票。」

→ 把本机四套技术口径**一次跑完**，指数和股票都支持；另加一个**买点分析**功能（第十一节），
指数 / 行业 / 概念 / 个股都能用。

主脚本：`bin/tech_summary.py`（单标的四层）+ `bin/tech_buypoint.py`（买点分析）。

| 层 | 口径 | 关键判定 |
|---|---|---|
| ① 缠论·分型版 | 包含处理→顶底分型→笔→中枢 ZG/ZD→背驰 | 日线认一二三买；**小时线只认三买 及 一买+MA10金叉** |
| ② 缠论·均线版 | 笔=MA5/10 双穿 MA20；线段=MA20/40 双穿 MA80；大级别=价格 vs MA160 | 只问「当前级别能不能支撑交易」，不递归、不用 MA320 |
| ③ SMC | 摆动点→结构突破→FVG / OB→方向确认（不破+回踩+方向≥2/4+不走远） | 日线 k=3，小时线 k=1；**只作机会/风险提示，不参与入场** |
| ④ VWAP 六轨 | 量加权 VWAP ± 1σ/2σ/3σ（窗口 60 根）+ MA40 方向 | +3σ 全平 / +2σ 减半 / -1σ 全止损；右侧标正态分位 |
| ⑤ 买点分析 | 买点：①三买 > ②一买(须MA20向上) > ③二买（**胜率最低，仅作参考**）；**卖点：三卖 > 一卖（须MA20向下）> 二卖**；行业先过闸才下钻个股；指数/行业/概念/个股通用 | `bin/tech_buypoint.py --target XXX`，见第十一节 |

## 二、用法

```bash

# 其它指数
python3 bin/tech_summary.py --target 上证50
python3 bin/tech_summary.py --target 000016.SH

# 股票（6 位代码自动判沪深；也可 SZ000001 / 600519.SH）

# 生成 + 推飞书卡片（文字报告 + 两张图，同一条消息）

```

**支持的指数中文名**：5 个宽基 + `EXTRA_IDX` 里补的（上证指数/上证综指/上证50/深证成指/中证100/中证200/中证800/中证红利/中证全指/北证50）。
要加新指数，往 `EXTRA_IDX` 加一行 `"中文名": "ts_code"` 即可。

**标的解析**：`resolve(target)` → `{kind, name, sina, ts, disp}`，支持中文名 / `000905.SH` / `sh000905` / `600519` / `600519.SH` / `SZ000001`。

输出：
- 文本报告（stdout，六节）
- `.cache/charts/tech_<标的>_day_<YYYYMMDD>.png`
- `.cache/charts/tech_<标的>_h1_<YYYYMMDD>.png`
- `--push` 时：飞书 interactive 卡片（文字分节 + 两图内嵌，同一条消息）

## 三、报告六节结构（顺序固定）

1. **结论（先看这里）** —— 每条一句话
2. **缠论·分型版** —— 日线 + 小时线；小时线买点按级别口径打 ✓/✗
3. **缠论·均线版** —— **日线 + 小时线 60m 两段**：笔/线段/大级别(MA160)/全均线排列/六条均线值/现价偏离%/MACD/背驰 + `tradeable()` 一句话；买卖点前缀 🌙/⭐
4. **SMC 结构** —— 日线(k=3) + 小时线(k=1)：结构类型、区间位置、新鲜 FVG/OB、买卖点确认
5. **VWAP 六轨** —— 日线/小时线两组，六条轨 + σ 偏离 + 正态分位 + 触发口径
6. **综合判断** —— ±1 打分制 + 倾向结论

## 四、综合打分口径（第六节）

每条 ±1，最后看总分：

| 条件 | 分 |
|---|---|
| 日线中枢上方 / 下方 | +1 / -1 |
| 日线底背驰 / 顶背驰 | +1 / -1 |
| 小时线已向上离开中枢 | +1 |
| 均线版本级有买点 / 在卖点 | +1 / -1 |
| 价格站上 / 跌破 MA160 | +1 / -1 |
| 日线 VWAP ≥ +2σ / ≤ -1σ | +1 / -1 |

| 总分 | 倾向 | 卡片颜色 |
|---|---|---|
| ≥ +2 | 偏多，等回踩结构支撑低吸 | green |
| +1 | 偏多但结构未确认，轻仓/等确认 | green |
| 0 | 中性，等方向选择 | blue |
| -1 | 偏空，反弹减持、不追多 | red |
| ≤ -2 | 空头结构，空仓等底部结构（背驰/三买） | red |

## 五、图的构成

一张图 = **四个面板**（价格 / 均线版 / 量 / MACD），从上到下：

**价格面板**
- K 线：**上色按 `close vs 上一根 close`**（涨跌幅口径），不是 `close vs open`
- 缠论笔（蓝线）+ 分型端点（红▽顶 / 绿△底）
- 中枢矩形（黄底 + ZG/ZD 虚线 + 「中枢」文字）
- 缠论分型版买卖点：**买点 = 🌙 绿月牙 / 卖点 = ⭐ 红星**（大佬 2026-11-09 指定），标注「买点/卖点 tag 价格 / N根前 / 长期未破」
- 均线版买卖点也画在价格面板上：绿月牙 / 红星 + 「均线买点/均线卖点」
- SMC FVG：点线虚框（绿=看涨 / 红=看跌），左侧标 `FVG<age>`
- SMC OB：虚线框（深绿=看涨OB / 紫=看跌OB）
- VWAP 六轨：`+3σ 深红实线 / +2σ 红虚线 / +1σ 浅红点线 / VWAP 黑实线 / -1σ 绿虚线 / -2σ 深绿实线`
- **右侧分位标注**：+3σ·99.9% / +2σ·97.7% / +1σ·84.1% / VWAP·50% / -1σ·15.9% / -2σ·2.3%

**均线版面板**（2026-11-09 大佬两次追加要求后的最终形态）

> 大佬原话：「不论是均线版还是分型版，你画图的时候一定要把这个结构画出来，缠论的结构，
> 尤其是你这个均线版，你肯定没画出来，你至少得把笔、线段、走势类型你画出来啊。」

**结构四件套（必须画，缺一不可）**，由 `ma_structure(df)` 算出（三处绘图共用）：

| 层 | 元素 | 口径（必须与 `chan-ma-trend` 技能一致） | 画法（深→浅） |
|---|---|---|---|
| 最上 | **线段** | `M.dual_cross_state(dd, *M.A1)` MA20/MA40 **双穿** MA80 | 深藏青 `#0d2b45` **lw 3.6** + 白边方块 + 「线段」标注 |
| ↑ | **笔** | `M.build_bi(dd)` MA5/MA10 **双穿** MA20 | 橙 `#e8955a` lw 1.3 + 小圆点 |
| ↑ | **中枢** | 线段的**连续三段重叠区** | 填充 `#ffd24d` alpha0.30 + 边框 `#c07800` **lw 2.2** + ZG/ZD 虚线 + 「中枢 ZD~ZG」 |
| 最底 | 走势类型 | `M.trend_mode(sub)`（每次向前算，MA5vsMA10、MA10vsMA20 近20根不接触） | 背景色带 上涨`#ffe3e3`/下跌`#e0f2e4`/盘整`#efefef`，**alpha 0.55 很淡** |

**均线只留三条 + MA160**（2026-11-09 大佬：「至少 MA20 均线就不用画了，我主要看出大结构」）：
- MA5 / MA10 / MA20：lw 0.7，**alpha 0.45**（极淡，只为看缠绕）
- MA160：紫 `#8e44ad` 虚线 lw1.3（大级别支撑，唯一保留的长均线）
- 收盘线：淡灰 `#b0b0b0` lw0.9
- ~~MA40 / MA80~~：**不画**（会糊住结构）

**窗口**：均线版子图独立 x 轴，默认 **400 根**（`TECH_MA_PANEL_BARS`）；
其它面板按 `--n-day`（默认 120）。260 根里常常只有 1-2 个中枢，看不出序列。

角标：右下角「多头/空头/混合排列 + 已持续根数」+「走势：X ｜ 笔 N ｜ 线段 M」。

⚠️ **走势类型不能用「相邻线段方向」判**：线段由状态翻转生成，方向必然交替，
一判就会 100% 变成「盘整」。必须用 `M.trend_mode()`（女上位/男上位/接触）。
⚠️ 极短段（<8 根）合并到前一段，否则图上一堆碎色块。
⚠️ **`axhline` 的 xmin/xmax 是轴坐标比例（0~1），不是数据坐标** → 画区间横线用 `hlines(ys, x0, x1)`。

**量面板**：与 K 线同色柱
**MACD 面板**：DIF/DEA + HIST（10/20/5，与 `chan_smc_index` 常量共用）

**标题栏**：`标的 · 日期/时间 ｜ 级别 ｜ 收 X 今日 ±x.xx%`
**副标题**：阶段 / 背驰 / 中枢区间 / `VWAP 值（±σ · 分位%）`

## 六、数据来源（指数/股票分别走不同链路）

| 标的类型 | 日线 | 小时线 60m |
|---|---|---|
| 指数（tushare 有权限的） | `chan_smc_index.fetch_daily()`（本地缓存 `.cache/chan_daily/`） | `minute_hub.get_kline(sina, "60", kind="index")` |
| 指数（其它，如 000016.SH） | `datahub.daily()` 三级灾备（akshare→tushare→web） | 同上 |
| 股票 | `datahub.daily()` 三级灾备（带 6 小时 CSV 缓存 `.cache/tech_daily/`） | `minute_hub.get_kline(sina, "60", kind="stock")` |

`datahub.daily()` 内部：L1 akshare（A股 qfq）→ L2 tushare（daily+adj_factor 自算前复权）→ L3 网页，带 OHLC 硬校验 + 新鲜度择优。

## 七、硬规矩（踩过的坑，别犯）

1. **禁 IPv6**：脚本开头必须挂 `socket.getaddrinfo` 过滤 `AF_INET`，否则 tushare/分钟线静默卡死
2. **K 线上色 = close vs prev close**，标题必须写 `今日 ±x.xx%`。低开高走涂成红阳线但实际跌，大佬抓过这个
3. **小时线买点不能裸认一买/二买**：一买要叠加 MA10 上穿 MA20 才 ✓，二买一律 ✗，只认三买
4. **SMC 的 FVG/OB 只作提示**，回测已验证无不可用 α（±0.3% 内），绝不参与入场判定
5. **VWAP 三档判定顺序**：先 `-2σ`/`-1σ` 止损 → 再 `+3σ` 全平 → 再 `+2σ` 减半 → 再 `+1σ` 警戒。不能 if/elif 并列 +2σ/+3σ
6. **VWAP 成交量含 0 值**要 `replace(0, nan)`，整窗量为 0 时退化为等权，避免 NaN
7. **图内文字不能用 emoji**（🟢🟡🔴 Noto CJK 无字形 → 豆腐块），改用颜色区分。
   **唯一例外**：月亮/星星标记不是 emoji，是 `TextPath` 从 `FreeSerif.ttf` 取的字形转成 matplotlib `Path` marker
   （U+263E 月牙 / U+2605 实心星），`glyph_marker()` 生成，`MOON` / `STAR` 两个常量。别改成 `ax.text("🌙")`，会豆腐
   ⚠️ 月牙字形**内部是空的**，填色要靠 `edgecolor` 同时描边（买点用 `edgecolor=col, lw=1.8~1.9`），否则只剩一圈线
8. **中枢矩形**是 alpha 0.25 叠加，像素校验要按混合色查（`255,244,210`）
9. **小时线取数是分钟线**：`minute_hub` 返回列名是 `day` 要 rename 成 `dt`
10. **⚠️ `minute_hub` 磁盘缓存 key 不含 `n`**：之前用 n=60 取过一次，n=400 会直接返回那份 60 根的旧缓存 → 误判「数据不足」。所以**长度不够时必须 `cache=False` 强制刷新再取一次**（已修，见 `load_h1`）
11. **`datahub.daily()` 有 tqdm 进度条**（akshare 分支），跑 cron 时 grep 日志要过滤 `it/s`

## 十、已知限制

- 单标的跑（`--target` 一次一个）。要批量看多个标的，循环调用
- 均线版日线 + 小时线**都跑**（2026-11-09 起）；`ma_layer(df, "h1")` 直接吃 60m df，报告「三」节下半段给小时线均线结论
- 缠论分型版的小时线买卖点做了口径过滤，**原始裸信号仍在 `fx_h` 里**，只是报告打 ✗
- 图默认显示最近 120/150 根，但**缠论几何用全量数据算**再按索引裁切（否则笔/中枢会变）
- 股票日线走 `datahub` 三级（akshare 26s 左右，含 tqdm 进度条）；有 6 小时 CSV 缓存
- 港股（5 位代码）tushare 多数账号无权限，会落到 L3 网页，可能拿不到，未验证

## 十一、买点分析（`bin/tech_buypoint.py`）—— 技能第五层功能

> 大佬 2026-11-09：「把这个变成一个技能，用这几个指数，就多一个功能是买点分析
> 但是不单单以后你分析股票、行业还有概念，这些都可以」

**核心口径（大佬 2026-11-10 最新，覆盖 11-09）：① 三买 > ② 一买（必须 MA20 向上）> ③ 二买（恢复，不再丢弃）**
**卖点：三卖 > 一卖 > 二卖（2026-11-10 新增正式输出）**

> 11-09 曾定「二买就不要了」；11-10 大佬改为「二买也恢复，排第三」。两者冲突时以 11-10 为准。

**执行顺序（大佬 2026-11-09 20:54 定稿）**：
> 「首先我让你分析行业有没有买点，如果行业有买点了，然后你再分析个股」

```
第一步：判行业/板块自己有没有买点（行业指数跑同一套三买/一买判定）
          ↓ 有买点
第二步：才下钻扫成分股，输出可买个股（三买优先，一买其次，二买第三）+ 全部卖点
          ↓ 没买点
       直接停：只输出行业结构，个股部分跳过
```

加 `--force-scan` 可强制下钻（调试用）。实测 31 个申万一级行业里只有 4 个过闸，
说明这个闸门不是摆设。

### 11.1 四类标的，一个入口

| kind | 输入示例 | 行为 |
|---|---|---|
| `index` | `中证500` / `上证50` / `000905.SH` | 指数自身结构 + **成分股买点扫描** |
| `industry` | `传媒` / `游戏` / `出版` / `银行` | 申万指数结构 + 成分股扫描 |

### 11.3 买点判定细则

**级别优先（大佬 2026-11-09 20:57）**：「优先是日线级别出现买点，然后才是小时线级别」

| 级别 | 用途 | 说明 |
|---|---|---|
| **日线** | **主判定** | 决定这只票算不算「可买」，三买/一买都在这层判 |
| 小时线 60m | 次级确认 | 只叠加不替代：日线有买点 + 小时线也有 = 精确入场点 |

小时线口径沿用 `chan_smc_index.H1_ALLOWED_BUY`：**只认三买**；一买须 MA10>MA20 金叉才认。
小时线参数独立：`SCAN_H1_TB_MAX_AGE`(120) / `SCAN_H1_TB_NEAR`(8) / `SCAN_H1_YB_MAX_AGE`(60)。

| 买点 | 条件（全部满足） |
|---|---|
| **三买** | ① 向上离开某个中枢（遍历**所有**中枢，不只看最后一个）② 回踩低点 > 该中枢 ZG ③ 回踩之后再未跌破该低点 ④ 买点年龄 ≤ `SCAN_TB_MAX_AGE`(90) 根 ⑤ 现价距买点 ≤ `SCAN_TB_NEAR`(10%) ⑥ **现价仍 > 该中枢 ZG** |
| **一买** | ① 底背驰 ② **MA20 向上**（`MA20(t) > MA20(t-5)`，`TECH_MA20_UP_BARS`；硬门槛，不过就不认）③ 年龄 ≤ `SCAN_YB_MAX_AGE`(40) 根 ④ 现价距买点 +`SCAN_BUY_NEAR_UP`(10%) / -`SCAN_BUY_NEAR_DN`(3%) 内 |
| **二买** | ① 回踩不破一买低点（`chan_smc_index` 的 `buy_list` 给出）② 年龄 ≤ `SCAN_EB_MAX_AGE`(**60**) 根 ③ 现价未跌破二买低点超 3%（跌破=结构破坏，不认）④ 现价距买点 ≤ `SCAN_EB_NEAR`(**10%**) ⑤ **MA20 向上只加分，不作硬门槛**（二买处在回踩确认阶段，均线常未拐头；与一买严格区分） |

> ### ⚠️ 二买胜率最低（大佬 2026-11-10 明确要求写进说明）
> **二买是三档买点里胜率最低的一档**，明显低于三买和一买：
> - 二买本质是「一买之后的**回踩**」，此刻趋势**尚未确认转多**，回踩既可能是缩量洗盘，也可能是破位下跌的中继；
> - 一买有「底背驰 + MA20 向上」双确认，三买有「离开中枢后回踩不破 ZG」的结构确认，**二买只有「不破一买低点」一个条件**，容错最低；
> - 实盘里二买出现后直接跌破一买低点、把信号做成假信号的概率明显更高。
>
> **所以二买只作观察/次优信号，不要单独用它下决定**，必须叠加 MA20 向上、量能、板块强度、大盘环境等确认。
> 报告里二买段标题带「（胜率最低·仅作参考）」，排序永远排在最后。

**买点优先级**：① 三买(`pri=1`) > ② 一买(`pri=2`) > ③ 二买(`pri=3`) —— 2026-11-10 大佬更新，二买**恢复，不再丢弃**。

**卖点判定细则**（2026-11-10 新增，`find_sells()`）

| 卖点 | 条件（全部满足） | pri |
|---|---|---|
| **三卖** | ① 向下离开某个中枢（遍历**所有**中枢：`segs[k]` 向下且 lo < ZD）② 反抽 `segs[k+1]` 向上且 hi < ZD（反抽不回中枢）③ 反抽后收盘**从未涨破**该高点 ④ 年龄 ≤ `SCAN_SELL_MAX_AGE`(90) 根 ⑤ 现价未涨破三卖价 ×1.03 ⑥ 现价距卖点 ≤ `SCAN_SELL_NEAR`(6%) | 1 |
| **一卖** | ① 顶背驰（`chan_smc_index` 的 `sell_list`）② **MA20 必须向下**（`slope < 0` 硬门槛，与一买须 MA20 向上严格对称；只背驰而均线还向上 → 不认，那通常是上涨中继回调）③ 年龄 ≤ 90 根 ④ 现价未涨破卖点 3% ⑤ 现价距卖点 ≤ 6% | 2 |
| **二卖** | ① 一卖后次高点 ② 同上年龄/涨破/距离闸门 ③ **MA20 向下只加分，不作硬门槛**（与二买对称） | 3 |

> 一卖被否时必须写清原因：「MA20 未向下（斜率 +x.xx%）→ 一卖不认」，不能笼统写「卖点被否」。
> 三卖不强制 MA20（结构已确认，同三买）。

> 卖点 `gap = 现价/卖点 - 1`：`gap < 0` = 现价仍在卖点下方、结构未破；`gap > 3%` = 已涨破卖点、**卖点失效**。
> 同一价位若被「三卖扫描」和 `sell_list` 同时命中，按价格去重，保留 pri 更高那条。

**质量排序**（`score_quality`）：站上 MA20 +1、站上 MA160 +1、多头排列 +2、买点新鲜(≤10根) +1、
**小时线也有买点 +1、小时线三买再 +1**。报告里单独列「日线+小时线双确认」清单。

### 11.4.2 ⚠️ 数据长度/缺口会造假信号（最严重的坑）

### 11.5 踩过的坑（血泪）

1. **`chan_read` 的三买只在最后一个中枢上找** → 传媒 129 只命中 **0 个**。扫描必须遍历所有中枢。
2. **一买不加距离闸门会爆表** → 三个月前的低点、现价翻倍也算「有买点」，129 只里 73 只全中。
3. **`find_third_buys` 判断「回踩低点是否被跌破」必须用合并K线 `mb`**，不能用原始 `close` 数组
   （`segs.i1` 是合并后索引，混用会导致 100% 误判「结构破坏」）。
4. **`datahub.is_index()` 永远返回 True**（600519.SH 也是），不能用它判断，要用 `is_index_code()` 按前缀规则。
5. **同花顺「中证500成份股」概念给的是 552 只**（含大量非成分股），只能兜底；中证官网才是准的 500 只。
6. **`akshare` 没有 timeout，会静默挂死** → 必须用 `_ak_timeout()` 包一层 ThreadPool 硬超时。
7. **报告里显示的中枢要用「该三买所属的中枢」**，不是最新中枢，否则价格对不上让人以为算错了。

## ⚠️ 2026-11-10 三处绘图口径修正（大佬「高低点都不一样了 / 末段没画出来」）

1. **笔/线段端点必须取「区间内真实极值」，不是状态翻转那根的收盘**
   `dual_cross_state` 翻转点是「均线穿完那根」，收盘 ≠ 本笔高低点。
   实测风语筑 up 笔翻在收 14.23，该笔区间实际最高 14.60 → 不修则整图峰谷全部缩水、位置偏移，
   与分型版图自然对不上。`ma_structure()._to_extremes()` 已统一处理（索引也归到极值那根，
   原翻转索引留在 `flip` 字段）。

2. **末笔/末段必须补「活端点」**（`live=True`）
   否则图右侧整段空白、走势类型也停住。活端点 = 从本笔极值那根至今的最高/最低。
   ⚠️ 起点用极值那根、不能用翻转那根，否则会把上一笔高点当本笔新高。
   绘图：live 末端从最后极值**虚线**连到最新收盘（tech_summary + buypoint_chart 同步）。

3. **走势类型分段不能用 `trend_mode()` 逐根跑**
   它要求 MA5/MA10/MA20 近 20 根完全不接触，日线 1200 根里只成立 1-3 根 → 整图一个灰块。
   走势类型是**线段级别**概念 → 比较相邻两摆的高低点：后高>前高且后低>前低=上涨；
   都降低=下跌；其余=盘整。⚠️ 配对必须「低点→高点」（seg 的 dir 是「从该点出发的方向」，
   按相邻两点直接配会错位一格 → 全部判成 range）。
