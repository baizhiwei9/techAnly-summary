# 缠论·均线版（趋势浪子原文口径）

> 权威依据：《趋势浪子的交易悟道之路》PDF（148 页）。
> **所有参数以原文为准，不要用口述版本。** 口述版和原文有三处重大差异，见文末对照表。

## 零、⚠️ 用途定稿：只看当前级别够不够交易（2026-11-08 大佬定稿）

**大佬原话：**
> 「我不需要递归啊。你缠论的那个递归，你需要干啥？你只要找买卖点得了。
> 你这个递归无非让我找更细的买卖点，我不需要。你只要当时出现买卖点，我就拿着就行了。
> 期货的话，我就上到下一级别，上到子级别去看了，然后那个 A2 是属于大级别，
> 那你没有的话我就不需要，**我只需要当前级别，够不够买卖点就行了，能不能支撑交易就行了**」

**所以本技能只回答一个问题：当前这个级别，有没有买卖点、能不能支撑交易。**

| 做法 | 要不要 |
|---|---|
| 递归（一个级别的笔由次级别段构成） | ❌ **不做** |
| A2 / 走势类型层 / MA320 | ❌ **取消**（大级别只看 MA160） |
| 当前级别的笔 + 线段 + 买卖点 | ✅ **只要这个** |
| 更高/更低级别的确认 | ❌ 不做；期货要看子级别是**人自己切换级别去看** |

### 📌 大级别支撑固定规则（大佬 2026-11-08 定稿，勿改）

> 「**如果三百二十均线数据不全，那你就不需要三百均线，你只需要穿越一百六十均线就行了**」
> 「你想判断能不能突破 320 均线，是不是？其实那你就不需要了，就只要突破 160 均线就行了。我大级别就能支撑了」

**规则：大级别支撑 = 价格 vs MA160，只用这一条。MA320 永久移除。**

为什么移除 MA320：
- MA320 需要 320 根数据，很多标的（新指数、次新股）凑不够 → 整个标的最被判「数据不足」丢掉
- 而「站上 160 均线」已经足够支撑交易判断
- 数据不全时**降级到 MA160**，不是报错、不是跳过标的

**数据门槛**：340 → **170 根**（够算 MA160 + 10 根余量）。不再要求 MA320。

**输出核心是这一行**：
```
【沪深300·日线】收 4054.28  → ⛔ 不宜做多（当前级别在卖点）
```
判定 `tradeable()`：
- ✅ 可以交易 —— 当前级别有买点
- ⛔ 不宜做多 —— 当前级别在卖点
- 🟡 无新鲜买点 —— 趋势向上，可持有不加仓
- ⚪ 无买点 —— 向下或盘整，空仓等

## 一、核心参数（原文铁律，勿改）

```
笔       = MA5 / MA10 双穿 MA20
线段     = MA20 / MA40 双穿 MA80
大级别支撑 = 价格 vs MA160        ← 不要 MA320（2026-11-08 定稿）
MACD     = (10, 20, 5)
```

均线池：`MA5 / MA10 / MA20 / MA40 / MA80 / MA160`（**已去掉 320**）

## 二、笔的定义 ——「双穿」不是单线金叉

**这是最容易做错的一条。**

原文（286-297 行）：
> 「当 5 日均线 10 日均线全部穿过 20 日均线后，又再次全部穿过，把行情的前面低点到后面高点连线成一笔。
> **注意是全部，5 穿过了 20 但 10 没穿过不成立；10 穿过了 20 但 5 没穿过也不行**。
> 5 穿过了 20 但 10 没穿过，后面 10 穿过了但是 5 又上去了也不行……
> 标准是要两条线依次全部穿过 20，且都是处于此状态下才行。」

数学表达（原文 294-297 行）：`a=MA5, b=MA10, c=MA20`
- `a > c` 且 `b > c` → **向上笔**
- `a < c` 且 `b < c` → **向下笔**
- 否则（一上一下）→ **中阴，不成笔**

状态翻转点即笔的转折点。

## 三、⚠️ 两个维度都要看：穿越 + 排列

**大佬 2026-11-08 关键补充（原文没写，但逻辑必然）：**
> 「它不一定是穿越，也可能是因为穿越还在很长时间了，也可能 MA40 和 MA20 和 MA80 就多头排列……
> **就多头排列，它也表示在很远很远的那个节点上，它就穿越了**」

**核心认知**：多头排列 = 很久以前穿越过、且之后一直没破。
如果只报「最近 N 根内的新鲜穿越」，**会漏掉绝大部分行情**。

**实测证据（沪深300 日线 2015-2026）**：
- 多头排列共 257 天
- 用「近 6 根内穿越」判定：**命中 0 天，漏掉 20/20**
- 2026-06-24 那天多头排列，旧逻辑报「无信号」

所以每一级必须同时报两个维度：

| 维度 | 含义 | 判定 |
|---|---|---|
| **排列** | 很久以前的穿越还在延续 | MA5>MA10>MA20>MA40>MA80>MA160（严格递减） |
| **双穿** | 当前方向 + 已持续多少根 | 见第二节，并给出 `age` |

## 四、⚠️ 排列的持续时长分级（回测结论，重要）

四宽基 2015-2026，排列出现后 **20 根** 的收益：

| 排列持续 | 沪深300 | 中证500 | 创业板指 | 上证50 | 解读 |
|---|---|---|---|---|---|
| **1-5 根** | -0.74% (45%) | -0.02% (48%) | +2.37% (59%) | -0.49% (47%) | **刚排齐，往往已涨一段 → 追不得** |
| **6-15 根** | +0.93% (66%) | +2.01% (61%) | +4.05% (64%) | +0.83% (57%) | **★ 最佳区间，排列站稳了还在走** |
| **16 根以上** | -0.87% (27%) | +1.86% (61%) | +5.30% (76%) | +0.49% (57%) | **分化，大盘蓝筹转负，创业板仍强** |

（括号内为胜率；基准：全样本 20 根平均 +0.30%~+0.53%，胜率约 51%）

**结论**：
- 多头排列**不是无条件买点**，要看排列已经持续多久
- **6-15 根是黄金区间**（四标的全部正向，胜率 57-66%）
- 1-5 根刚排齐时反而偏弱（追高盘）
- 16 根以上要分标的：沪深300/上证50 已透支（胜率掉到 27%/57%），创业板指仍在趋势中

## 五、三级联立（笔 → 线段 → 走势类型）

原文（457-490 行）：
> 「MA5/10/20 均线组，我就作为一个最基础的级别标准……
> 增加 MA40 和 MA80 两根均线，就可以形成放大 4 倍的均线系统……
> 在此 **笔--线段--走势类型** 递归完成。」

| 级别 | 均线组 | 判定 | 放大倍数 |
|---|---|---|---|
| 笔 | MA5 / MA10 / MA20 | MA5、MA10 双穿 MA20 | 最小 |
| 线段 | MA20 / MA40 / MA80 | MA20、MA40 双穿 MA80 | 4 倍 |
| **大级别支撑** | **价格 vs MA160** | 价格在 MA160 上/下 | — |

⚠️ 原文写的是 MA80/160/320 三级，但**大佬定稿只用 MA160 判断大级别支撑**，MA320 已移除。
理由：MA320 需要 320 根数据，很多标的凑不够；而「突破 160 均线」已经够支撑判断了。

原文（471 行）：「**一个级别的笔，必然是其次级别的段**」。

⚠️ 第三层叫 **走势类型**，**不要叫「分型」**（分型是分型版的概念）。

## 六、级别联立性 —— 为什么日线版就看日线

原文（439-455 行）：
> 「日线图上 MA4 和 MA8，120 分钟图上换算为 MA8 和 MA16，60 分钟图上换算为 MA16 和 MA32……
> 这里的重点是**保持一致**，也就是大小周期联立。」

**结论**：日线版跑日线，周线版跑周线。**不要自作主张降级到 4 小时或 60 分钟。**

## 七、趋势判定 —— 女上位 / 男上位

原文（751 / 776 行）：
> 「趋势的概念，实际上是相邻两组均线**不接触**形成**女上位**的状态…**男上位**是向下趋势。」

判定：最近 N 根内短均线与长均线**从未交叉** → 女上位（向上）/ 男上位（向下）/ 接触（盘整）。

同级别走势只有三态（原文 838 行）：**趋势上涨 / 趋势下跌 / 盘整**。

## 八、背驰

原文（700-730 行）：
> 「A0 级别的转折在 MACD 上看必然要有三个流程：
> **1、柱子缩短，2、黄白线交叉，3、黄白线回零轴附近或者穿越零轴**，少一个就不可能转折。」

判据（必须**同级别**）：
- 顶背驰：两段上涨笔，后段价格创新高，但 MACD 柱面积（力度）衰减 < 前段 90%
- 底背驰：两段下跌笔，后段创新低，力度同样衰减

⚠️ **力度区间** = 本笔起点 → **下一笔起点**（不是到末根）。最后一段还在走的笔，区间取到末根。

⚠️ 原文（710 行）：「指标的背离不一定意味着转折……**背离跟背驰是有区别的**，背驰的结论必然是在同级别的角度上才能下的，所谓背了又背是不存在的。」

## 九、买卖点

原文（730-770 行）：
> 「均线视角下的买卖点，并不和缠师中的 123 类买卖点相同，因为传统缠论的买卖点是针对中枢而言，而均线的买卖点，只针对某根或某组 MA 均线组而言。」

**两种来源都要报**：
1. **新鲜穿越**（转折点）：最近 look 根内 笔 由下转上 / 由上转下
2. **长期排列**（延续态）：排列已维持 N 根 —— 附持续时长分级提示

- 一类买点 = 笔由下转上的转折点（`dn → up`）
- 一类卖点 = 笔由上转下的转折点（`up → dn`）
- 延续点（二三买）= 上涨笔中，快线回踩但不接触慢线的任何一次转折
- 原文（875 行）：「**每个转折都是买卖点，但级别不同**。」

### 9.1 当前位置：在笔上还是笔下、接下来怎么走（`bi_walk()`，2026-11-09 大佬要求）

只靠「有买点/有卖点」不够用——大佬要的是「**我现在在哪一笔里，接下来怎么走，盯哪几个价**」。
`M.bi_walk(df)` 回答这个，输出固定四段：

```python
{"ok": True, "state": "up|dn|mid",      # 双穿状态
 "where": "笔上（上笔运行中）",           # 人话位置
 "start": 本笔起点极值, "ext": 前高/前低,  # 两个关键价
 "advice": "怎么走（一句话指令 + 触发价）",
 "ctx": "级别关系（顺级别/逆级别/缠绕）+ MA160 大级别",
 "levels": [("MA20", x), ("本笔起点", y), ("前高", z)]}
```

**判定口径（全部复用原文双穿，不另写一套）**

| state | 含义 | `where` |
|---|---|---|
| `up` | MA5、MA10 **同时**站上 MA20 | 笔上（上笔运行中） |
| `dn` | 两条**同时**跌破 MA20 | 笔下（下笔运行中） |
| `mid` | 一上一下 = 笔内缠绕，笔还没走成 | 笔内（缠绕 / 向上临界 / 向下临界） |

`mid` 再细分三档（**这是最实用的部分**，因为大部分时间都在缠绕里）：
- **向上临界**：MA5 已上穿 MA20、MA10 还差一点 → 报「MA10 补上（≈MA20 价）才成立上笔」
- **向下临界**：MA10 还在上方、MA5 已破 → 报「MA10 也跌破就走下笔，先减不加」
- **缠绕**：分居两侧 → 报「等双穿成立再动，别猜方向」

**关键位怎么取（⚠️ 别用 `build_bi().px`）**
- 本笔起点 = 该笔区间内的**真实极值**（up 笔取区间 `low` 最小、dn 笔取区间 `high` 最大）
- 前高/前低 = **上一个同向笔**（隔一笔 = `k-2`）区间内的极值
- `mid` 状态不谈前高前低（笔还没成立），改报「近 20 根区间高/低」

**级别关系（`ctx`）——决定这一笔能不能做**

| 本笔 | 线段 | 结论 |
|---|---|---|
| up | 向上 | 顺级别，线段上涨里的一笔 → 可持有 |
| dn | 向下 | 顺级别，线段下跌里的一笔 → **别抢** |
| up | 向下 | **逆级别反弹** → 前高附近先减 |
| dn | 向上 | 顺级别回踩 → **笔转折就是回踩买点** |

再叠加一条 MA160：跌破大级别时 `ctx` 末尾追加「⚠️ 已跌破 MA160 大级别支撑」。

**出口**：`chan_ma_trend_v2.render()/analyse()`、`tech_summary` 的结论①+第三节（日线/小时线）、
`tech_summary.draw_chart()` 均线版面板顶部居中标注（颜色：up 红 / dn 绿 / mid 金）。

## 十四、校验方法

1. 手算 MA5/MA10/MA20/MA160 与库值逐值比对
2. 手算 MACD HIST 与库值比对
3. 双穿判定逐根核对（`MA5>MA20` **且** `MA10>MA20` 才是向上笔）
4. **排列判定验证**：找一个历史多头排列日，确认能报出「多头排列延续」
5. 背驰力度复核：打印两段笔的区间与 hist 面积之和
6. **笔极值验证**：`build_bi()` 的 `px` 是**翻转那根的收盘**，
   不是这一笔的高低点 → 要取区间极值必须自己按 `high/low` 算（见 14.1）。
   画图侧 `tech_summary.ma_structure()` 已经统一处理，**不要直接用 `build_bi().px` 画峰谷**。
7. **`bi_walk()` 自检**（三态都要覆盖到，跑这三只就能测完 up/dn/mid）：

```python
import sys; sys.path.insert(0, "bin")
import chan_ma_trend_v2 as M, tech_summary as T
for name in ("600519", "中证500", "603466"):        # up / dn / mid
    dd = M.add_ind(T.load_day(T.resolve(name)))
    w = M.bi_walk(dd)
    assert w["state"] == str(M.dual_cross_state(dd, *M.A0).iloc[-1])   # 与双穿一致
    assert w["where"].startswith({"up": "笔上", "dn": "笔下", "mid": "笔内"}[w["state"]])
    names = [x[0] for x in w["levels"]]
    if w["state"] == "mid":
        assert "近20高" in names and "近20低" in names     # 缠绕里不谈前高前低
    else:
        assert "本笔起点" in names                          # 笔上/笔下必须给起点
    print(name, w["where"], w["levels"])
```

### 14.1 ⚠️ 关键坑：`build_bi()` 的 px ≠ 笔的高低点（2026-11-09 大佬抓出）

```python
bi = M.build_bi(dd)     # px = 状态翻转那根的 **收盘价**
```

「翻转」= MA5/MA10 双穿状态切换完的那一根，它的收盘价既不是这一笔的最高也不是最低。
实测 603466 风语筑：up 笔翻转于 i=1185 收 **14.23**，该笔区间实际最高 **14.60**（差 2.5%）；
线段更明显（11.00 vs **11.50**）。直接拿 `px` 画图 → 峰谷整体缩水、位置偏，
和分型版图自然对不上。

**正确取法**（`tech_summary.ma_structure()._to_extremes()` 的实现）：

```python
# 本点方向 up（= 从低点起涨）→ 取 [本翻转点, 下一翻转点] 区间内 low 最小
# 本点方向 dn（= 从高点起跌）→ 取同区间 high 最大
a = p["flip"]                                   # 翻转索引（不是极值索引）
b = next_p["flip"] if next else len(df) - 1
px = lo[a:b+1].min() if p["dir"] == "up" else hi[a:b+1].max()
```

**末笔必须补活端点**：最后一笔还没翻转，`build_bi()` 不会给它终点 → 图上右侧一大段空白。
要追加一个 `live=True` 的点，取「本笔极值那根 → 最新一根」的极值。
⚠️ 起点必须用**极值那根**，不能用翻转那根（否则会把上一笔的高点当本笔新高，
风语筑会取到 10-26 的 15.98，比现价 13.94 还高）。

## 十六、绘图规范（2026-11-09 大佬定稿，与 tech-summary 技能共用同一实现）

> 大佬原话：「你这个线段没画出来，中枢没画出来。如果你觉得乱的话，那你就画几个结构的，
> 至少 MA20 均线就不用画了。我主要看出大结构啊。你可以甚至不用把均线画出来。

**画图必须突出结构、弱化均线**。均线是「因」，结构才是「果」，用户要看的是果。

### 16.1 绘制优先级（深 → 浅）

| ↓ | 收盘线 | 淡灰 `#b0b0b0` lw0.9 | 不做 K 线，避免抢结构 |

>
> 大佬 2026-11-10 原话澄清：「**我不是要求去掉 MA5，我是要求你画图的时候不要画 MA5，

### 16.2 中枢怎么算（均线版）

均线版原文没直接讲中枢（它讲均线组缠绕），结构上等价于**线段的连续三段重叠区**：

```python
for k in range(len(segs) - 2):
    a, b, c = segs[k], segs[k+1], segs[k+2]
    zd = max(min(a.px, b.px), min(b.px, c.px))     # 三段低点的最大值
    zg = min(max(a.px, b.px), max(b.px, c.px))     # 三段高点的最小值
    if zg > zd:                                     # 有重叠 = 中枢
        ...
```

**合并规则要严**：只有「时间重叠 且 价格区间高度重合（ZD/ZG 差异 < 区间 50%）」才合并。
否则会把一整年缠成一个大方块（实测中证500 并出过 770 根宽的怪东西）。

⚠️ **这里的 `px` 必须是 17.1 的「区间真实极值」**，用 `build_bi().px`（翻转那根收盘）
会把中枢的 ZG/ZD 算歪 —— 中枢是靠线段端点算的，端点错中枢就错。
另外「太宽的」（`i1-i0 > 窗口 35%`）不该画，那不是中枢是长期震荡。

### 16.3 窗口长度

均线版子图**独立 x 轴，默认 400 根**（`TECH_MA_PANEL_BARS`）。
理由：线段的级别比笔大，260 根里常常只有 1-2 个中枢；400 根能看到完整的中枢序列。
其它面板（价格/量/MACD）仍按 `--n-day`（默认 120）。

### 17.1 笔/线段端点 = 区间真实极值

| | 旧（错） | 新（对） |
|---|---|---|
| 取值 | `build_bi()` 的 `px` = **状态翻转那根的收盘** | 该笔区间内 `high` 最大 / `low` 最小 |
| 索引 | 翻转那根 | **极值那根**（原翻转索引存 `flip` 字段备查） |
| 风语筑实测 | up 笔 14.23 / 线段 11.00 | up 笔 **14.60** / 线段 **11.50** |

详见 14.1。

### 17.2 末笔/末段补 `live` 活端点

`build_bi()` 只给**已翻转**的点 → 最后一笔还在走、没有终点 → 图右侧整段空白，
走势类型也跟着停住。

修法：末点后追加 `{"live": True, ...}`，取「本笔极值那根 → 最新一根」的最高/最低；
绘图时从最后极值**虚线**连到最新收盘（一眼看出「这一段还在走」）。
⚠️ 起点用**极值那根**、不能用翻转那根，否则把上一笔高点当本笔新高
（风语筑会取到 15.98 > 现价 13.94）。

### 17.3 走势类型分段：按摆动高低点，不用 `trend_mode()` 逐根

**旧做法为什么错**：`trend_mode()` 要求 MA5/MA10/MA20 近 **20 根完全不接触**才算趋势。
日线 1200 根里只成立 1~3 根 → 合并极短段后整图就是**一个 899 根的灰底**，等于没画。
`trend_mode()` 的正确用途是回答「**当下这一根**是什么状态」，不是画历史。

**正确做法**（走势类型是**线段级别**的概念）：

```python
# 摆 = 线段端点配对：低点 → 高点
swings = [(low, high) for 相邻两段 if a.dir=="up" and b.dir=="dn"]

后高 > 前高 且 后低 > 前低  → 上涨
后高 < 前高 且 后低 < 前低  → 下跌
其余                        → 盘整
```

⚠️ **配对必须「低点→高点」**：线段的 `dir` 是「从该点出发的方向」，
起点可能是高点；按「相邻两点」直接配会错位一格 → 实测风语筑 11 摆全判 `range`。

实测结果：风语筑 4 段 / 中证500 6 段 / 沪深300 6 段 / 茅台 4 段。
